Transparence financière

Où va l'argent ?

Un outil transparent se doit d'être transparent sur ses propres finances. Voici tout, sans rien cacher.

Aujourd'hui (phase beta), Nidham ne coûte rien aux mosquées. Le logiciel tourne sur un Raspberry Pi (35–80€, fourni ou acheté par la mosquée). Le développement est entièrement bénévole — conçu sur le temps libre, par conviction.

Si le projet grandit, des coûts réels apparaîtront : infrastructure, comptes développeurs, et potentiellement des compétences extérieures (designers, développeurs bénévoles ou freelances). Plutôt que de vous le découvrir plus tard, voici tout maintenant. Cliquez sur chaque ligne pour les détails.

🖥️
Matériel — Raspberry Pi par mosquée
Coût unique, propriété de la mosquée
35–80€ Phase beta ▼

Nidham tourne sur un Raspberry Pi 4 ou 5 installé dans vos locaux. C'est un achat unique, la mosquée en est propriétaire. Aucun loyer mensuel, aucune dépendance à un serveur externe.

Pendant la phase beta, nous accompagnons gratuitement l'installation et la configuration. Si une mosquée ne peut pas assumer ce coût, nous cherchons des solutions — c'est justement à ça que peuvent servir les soutiens reçus.

  • Raspberry Pi 4 (2GB) : ~35€
  • Raspberry Pi 5 (4GB, recommandé) : ~60–80€
  • Carte SD + alimentation : ~15€ (inclus dans certains kits)
⏱️
Temps de développement
Actuellement 100% bénévole
0€ Bénévole ▼

Nidham est développé sur le temps libre, par conviction que la communauté mérite un outil digne de ce nom. Chaque fonctionnalité, chaque bug corrigé, chaque déploiement — c'est du bénévolat.

Si le projet grossit, nous pourrions avoir besoin de compétences supplémentaires : un designer pour l'app mobile, un développeur pour le portail adhérents, un testeur, etc. Nous privilégierons d'abord les bénévoles de la communauté, puis des freelances si nécessaire.

Si nous faisons appel à des freelances, les montants seront publiés ici, avec ce qui a été fait et pourquoi.

🌐
Infrastructure — Domaine & emails
Coût actuel du projet en ligne
~8€/an Actuel ▼

Le seul coût récurrent actuel est le nom de domaine nidham.fr (~8€/an). Les emails transactionnels passent par Brevo, gratuit jusqu'à 300 mails/jour — largement suffisant pour l'instant.

  • nidham.fr : ~8€/an (OVH, engagement 3 ans)
  • nidham.app : ~15€/an (si pris pour l'international)
  • Emails Brevo : 0€/mois (plan gratuit)
☁️
Serveur cloud — Portail adhérents (futur)
Nécessaire pour accès hors mosquée
~20€/mois Futur ▼

Aujourd'hui, Nidham fonctionne en mode local — accessible uniquement depuis le réseau de la mosquée ou via tunnel sécurisé. C'est voulu : vos données ne bougent pas.

Quand nous développerons le portail adhérents (accès depuis chez soi), nous aurons besoin d'un petit serveur cloud comme relais sécurisé. Les données resteraient chiffrées et la mosquée garderait le contrôle.

Ce coût sera mutualisé entre toutes les mosquées utilisatrices — pas répercuté individuellement. C'est pour ça que les soutiens collectifs comptent.

📱
Application mobile — Comptes développeurs
Pour publier sur App Store & Google Play
~115€ Futur — 2027 ▼

Pour publier une app sur les stores officiels, il faut payer des frais d'accès développeur :

  • Apple Developer Program : 99$/an (~95€) — obligatoire pour iOS
  • Google Play Console : 25$ une seule fois (~24€) — pour Android

Ce sont des coûts uniques ou annuels, pas récurrents. Ils seront engagés uniquement quand l'app sera prête et testée.

💼
Si Nidham devient SaaS — Modèle économique
Comment le projet pourrait s'autofinancer
À définir Réflexion ▼

À terme, si Nidham grossit et nécessite des ressources importantes, nous envisageons un modèle freemium éthique :

  • Gratuit à vie : version locale sur Raspberry Pi, toutes les fonctions de base
  • Soutien libre : les mosquées qui peuvent contribuent ce qu'elles veulent
  • Option cloud (payante) : si une mosquée veut un hébergement géré par Nidham, sans Pi — un abonnement mensuel modeste (~10–20€/mois)
  • Fonctions premium : app mobile, portail adhérents avancé — uniquement pour financer leur développement

Ce qui ne changera jamais : la version locale restera gratuite. Personne ne sera forcé de payer pour accéder à l'essentiel.
